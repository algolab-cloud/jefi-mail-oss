# Jefi Mail 0.9.1

HTML mail that fits the conversation, and a smoother reader.

- **HTML mail at its full height.** An HTML message is now exactly as tall as its content, so the conversation scrolls as one, with no box scrolling inside it. Its ends are no longer cut off under the reply box, and its rounded corners show as you scroll past them. Scrolling over a message moves the conversation.
- **HTML mail in your theme.** Plain HTML mail, without its own colours, now follows the theme: in dark mode it reads light on a dark card. Newsletters and other mail with their own design keep their look.
- **Better AI summaries.** The summary header no longer overlaps the text. A finished summary or translation can be copied, or taken to the assistant with "Ask about it in the chat". The assistant now uses Claude Sonnet 5.5 by default.
- **Copy with ⌘C.** Text you select in a message, a summary or the assistant's replies copies with ⌘C.
- **Long menus scroll.** With many labels, the label menu fits the window and scrolls, so every label and "New label…" can be reached.
- **Steady tooltips.** Tooltips on the reader's toolbar open below their buttons instead of flickering.

Every download is signed and notarized by Apple, and comes with a build attestation linking it to the public commit it was built from.

Requires an Apple silicon Mac running **macOS 13 or later**.
