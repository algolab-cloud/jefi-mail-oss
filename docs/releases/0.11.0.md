# Jefi Mail 0.11.0

An assistant that works more like the AI you're used to, and safer handling of attachments, unsubscribe links and changes to your mail.

- **Chat about any email.** Right-click a conversation, or use the ⋯ menu on a message, and choose Chat about this thread. Select several conversations to ask about them together, from the right-click menu or the ✦ button in the selection bar. In the chat box, type @ to bring in another email or a person.
- **Drafts you can shape in the chat.** When the assistant writes an email or a reply, it shows the draft in the chat instead of opening the composer straight away. Make it shorter, more formal or friendlier with one click, copy it, or open it in the composer to send.
- **Undo, right in the chat.** Anything the assistant archives, trashes, stars, marks, snoozes or labels gets an Undo on the spot, and the assistant is told what you took back.
- **Answers that show their sources.** The emails an answer talks about appear under it as cards you can click to open. Each answer ends with suggested follow-up questions, and you can regenerate it when it didn't change anything in your mailbox.
- **Copy and edit.** Copy any message, any answer or the whole chat. Edit and resend something you asked, or try again after an error.
- **Chat history.** Chats are kept on your Mac so you can reopen them from the clock button. Turn this off, or delete them all, in Settings → AI.
- **Writes like you.** Settings → AI has a new "About you and how you write" box. What you write there goes with every assistant request and every AI draft, including Write and Rewrite in the composer.
- **Reads attachments.** The assistant can read PDFs, Word and RTF documents, HTML and text files attached to your mail, using what's built into macOS.
- **Safer attachments.** Downloaded and saved attachments are marked as coming from the internet, so macOS checks them before they run. Files that could run programs or install software are shown in Finder instead of being opened.
- **Safer one-click unsubscribe.** One-click unsubscribe only goes to ordinary https addresses on the public internet, and never follows redirects.
- **Changes your mail server refuses aren't lost.** If the server turns down a move, delete or flag change, Jefi tries again instead of treating it as done. If a change can't be made at all, Jefi undoes it on your Mac and tells you. "Delete forever" in Clean up deletes only the mail it lists, and never your Sent or Drafts copies.
- **Your data stays private.** Jefi's data folder and the files in it can only be read by you. Your mail database is backed up before each upgrade, and a damaged Keychain vault is set aside instead of breaking every sign-in.
- **Faster clean-ups.** Queuing thousands of moves from Clean up is several times faster.

Every download is signed and notarized by Apple, and comes with a build attestation linking it to the public commit it was built from.

Requires an Apple silicon Mac running **macOS 13 or later**.
