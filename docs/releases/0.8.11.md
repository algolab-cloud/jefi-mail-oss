# Jefi 0.8.11

Right-click where you'd expect to.

- **Copy from the reader.** Right-click a message to copy what you've selected, the whole message text or the sender's address, or to reply, forward, add it to notes, make it a task or print it. HTML mail shown in full keeps macOS's own menu, with Copy and Look Up.
- **Tasks at a right-click.** Right-click a task in the list or on the board to open it, mark it done or reopen it, change its status or priority, or delete it, with the same Undo as the keyboard and the task sheet.
- **Notes too.** Right-click a note to open it, pin or unpin it, or delete it. Deleting a note you aren't reading leaves the one you are open, and anything you've just typed in it is kept.

Requires an Apple silicon Mac running **macOS 13 or later**.
