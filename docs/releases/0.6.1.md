# Jefi 0.6.1

A quick fix for the first launch after updating to 0.6.

- **Dialogs stay on top.** If an HTML email was open when Jefi started, it could cover the What's new sheet, and a message that finished loading while a dialog was open could cover that dialog too. Dialogs now always appear above the message, which shows again as soon as the dialog closes.

Requires an Apple silicon Mac running **macOS 13 or later**.
