# Jefi 0.8.7

A faster calendar, and text that reads right in every language.

- **A calendar that keeps up.** Moving to the next week, day or month used to rebuild the whole grid; now it stays in place and only the events change, with the weeks either side ready before you get there. The agenda draws only the days on screen, so it scrolls smoothly however far ahead you look.
- **Less work everywhere.** Jefi no longer resends unchanged styles to the screen on every update, which makes the whole app a little lighter.
- **Right-to-left text done right.** Subjects and titles in Arabic or Hebrew, or mixed with English like "Re: …", read in the right order and are shortened at their reading end, in the mail list, toasts, the reader and the calendar.
- **New events stay in sight.** An event you create is shown where it landed, even in another week, instead of seeming to vanish after you save it.

Requires an Apple silicon Mac running **macOS 13 or later**.
