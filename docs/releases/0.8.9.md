# Jefi 0.8.9

The last of the mail speed-ups.

- **Archive in a blink.** Archiving, deleting, moving or labelling a conversation used to be followed by a sync of your whole mailbox; now the change goes straight to the server and, when the server confirms where the message went, nothing more is needed. Your own change coming back from the server no longer starts another sync either. Archiving takes less than half the work it did.
- **Smoother reading.** Moving to the next conversation keeps the reading pane in place and changes only what differs, and unread counts in the sidebar, the Dock and the menu bar update in the same step instead of a moment later.

Requires an Apple silicon Mac running **macOS 13 or later**.
