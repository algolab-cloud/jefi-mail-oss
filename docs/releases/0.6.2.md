# Jefi 0.6.2

Faster with large mailboxes.

- **Scroll back further, faster.** Older mail now loads a page at a time from where you left off, instead of reloading everything above it. Deep in a mailbox of tens of thousands of messages, each page arrives several times faster.
- **Less work when nothing changed.** Jefi keeps a running record of what the mail list shows, so routine checks that find nothing new cost next to nothing.
- **No pause for the phishing list.** When phishing-list downloads are turned on in Settings, the list is now loaded and updated in the background. Link reviews and Link Protection settings open without waiting, and the list uses far less memory once loaded.

Requires an Apple silicon Mac running **macOS 13 or later**.
