# Jefi 0.5.0

This update adds safer email links and improves reading, composing, and recovery.

- Review a link's destination before opening it. Hover or use the keyboard to see domain warnings, including misleading link labels.
- Manage trusted domains in Settings. Jefi checks downloaded Phishing.Database lists locally; optional Google Web Risk checks use your own API key stored in Keychain and run only when requested.
- Format selected text in the composer with the toolbar or keyboard shortcuts, with native Undo support.
- Preview and save attachments, view original messages and headers, find text, and print or save a message as PDF.
- Improved reply recipients, outgoing-mail retries, offline recovery, notification opening, and licence recovery.
- Updates now recheck the download and staged app before installation.
- Founding licence counts appear only after 30% have been claimed.

Requires an Apple silicon Mac running **macOS 13 or later**.

[Download Jefi 0.5.0](https://downloads.jefi.app/releases/0.5.0/Jefi-0.5.0.dmg)

Google Web Risk is optional and requires your own Google Cloud API key. Checking a link with Google sends its full URL, including any private query tokens; hovering and local checks do not.
