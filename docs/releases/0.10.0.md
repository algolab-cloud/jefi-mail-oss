# Jefi Mail 0.10.0

A smart clean-up that knows junk from mail that matters, a tidier Settings, and HTML mail that fits the conversation.

- **Smart clean-up.** Clean up → Smart asks your AI to sort the senders in your Inbox into junk, not sure and important. It goes by what each sender sends and how you deal with them: anyone you write to, answer or flag is never called junk. Archive or trash a sender's mail in one click, with Undo.
- **Important mail inside the junk.** Before anything is moved, the clean-up reads through each junk sender's mail for messages worth keeping, like sign-in codes, receipts and shipping notices. It keeps those, and you can choose to keep any other message or sender yourself.
- **Real mail in Spam.** The clean-up also looks through Spam for mail that isn't spam, such as a reply from someone you know or a real invoice. Each one comes with a Not spam button. Phishing stays where it is.
- **Scheduled clean-up.** Settings → Clean up can run the clean-up daily or weekly while Jefi is open. A scheduled run can just report what it found, or archive the junk or move it to Trash. You can pick a separate AI model for clean-ups.
- **Settings, organised.** Settings now has its own menu with General, Mail, AI & tools and About, and a search box that finds any setting.
- **Rules show what they'll catch.** As you edit a rule, it shows how many conversations it matches right now. If "Is from a mailing list" is leaving some out, it says how many and offers to include them.
- **One Jefi per mailbox.** If a second copy of Jefi opens on the same mail, it brings the first one forward and closes, instead of both fighting over the mailbox. That fixes "database is locked" errors and rules that stopped half-way.
- **Faster changes on Gmail.** Archiving, moving and deleting lots of mail reaches Gmail many times faster.
- **HTML mail at its full height.** An HTML message is now exactly as tall as its content, so the conversation scrolls as one, and nothing is cut off under the reply box. Plain HTML mail follows the theme, so it reads light on a dark card in dark mode. Mail with its own design keeps its look.
- **Better AI summaries.** The summary header no longer overlaps the text. A summary or translation can be copied, or taken to the assistant with "Ask about it in the chat". The assistant now uses Claude Sonnet 5.5 by default.
- **Smaller fixes.** ⌘C copies text you select. Long menus, such as labels, fit the window and scroll. Toolbar tooltips no longer flicker.

Requires an Apple silicon Mac running **macOS 13 or later**.
