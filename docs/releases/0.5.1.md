# Jefi 0.5.1

This update keeps your email visible while reviewing links and makes optional protection easier to manage.

- **Your email stays visible.** Opening a link review no longer replaces the formatted HTML message with an empty canvas. Closing the popover returns to the live email view.
- **A smaller link popover.** Review the destination, copy it, cancel, or choose Open anyway when a warning applies. Additional warnings can be expanded.
- **Protection services are optional.** Phishing-list downloads are off by default and can be enabled in Settings. Google Web Risk uses your own API key and runs only when requested. Neither is required to open a link.
- **Less clutter.** Link reviews no longer prompt you to add an API key or display routine phishing-list status. Reported threats still show a warning.
- **Faster reading.** Link scanning in long messages is substantially faster. Temporary canvas images are released after the popover closes to avoid accumulating cached images.

Requires an Apple silicon Mac running **macOS 13 or later**.
