# Jefi Mail 0.8.14

A friendlier first launch, and mail that never goes out twice.

- **A new welcome.** Setting up is six short steps, each with its own illustration: say hello, connect your mail (or look around with a demo mailbox), pick a colour and a light or dark look, turn on notifications, and you're in. Everything else has a sensible default and stays in Settings.
- **Never sent twice.** If the connection drops after your message reached the server but before it confirmed, Jefi Mail no longer sends it again on its own. The message waits in the Outbox as Not confirmed, and you choose: It was sent, or Send again. If its copy turns up in Sent, it's marked sent by itself.
- **Solid where it should be.** In Liquid Glass, the floating assistant and dialogs no longer let the mail behind them show through.

Requires an Apple silicon Mac running **macOS 13 or later**.
