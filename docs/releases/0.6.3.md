# Jefi 0.6.3

Smoother scrolling, faster find, and less work while Jefi sits idle.

- **Steady scrolling.** Scrolling back through a large mailbox no longer jumps the list up by a screenful when older mail loads in.
- **Find keeps up.** Searching inside a long conversation now responds instantly to each keystroke instead of re-preparing every message as you type.
- **Quieter when idle.** An open HTML message checks its position far less often once nothing is moving, and the Compose button's animation pauses when Jefi isn't the app in front or when Reduce motion is turned on in macOS.

Requires an Apple silicon Mac running **macOS 13 or later**.
