# Jefi 0.8.6

Smoother, especially with a lot on your plate.

- **Big lists that stay quick.** Tasks and notes now draw only what's on screen. With 2,000 tasks, moving through them with J and K is more than ten times faster, and opening a task or switching to the board no longer pauses.
- **Typing without lag.** A keystroke used to redraw the whole composer, reply box, note or task around it. Now only the text changes, so long notes and task descriptions type smoothly and big emails keep up with you.
- **Quieter when idle.** The Compose button's stripes move only while the pointer is over it, and the sidebar and rail no longer redraw for changes they don't show, so Jefi uses far less energy while it sits in front.
- **Links within a message.** A table of contents or "back to top" link in an HTML email scrolls to its spot instead of showing Link blocked.
- **A clearer warning.** A mail link that hides a line break, a way to slip in extra recipients, is blocked with a warning that says exactly that.

Requires an Apple silicon Mac running **macOS 13 or later**.
