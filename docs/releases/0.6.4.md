# Jefi 0.6.4

Faster lists and search in big mailboxes, and less redrawing everywhere.

- **Lists open instantly.** Jefi now keeps a small index of your conversations, so opening a folder or scrolling back through tens of thousands of messages reads a page straight from it instead of regrouping the whole mailbox each time.
- **Quicker search.** Results are gathered from the search index directly, so broad searches come back noticeably faster.
- **Less redrawing.** When mail syncs or you type, only the parts of the window that actually changed redraw, which keeps Jefi light while you read and write.
- **Tidier Outlook messages.** Some Outlook messages no longer show an extra blank line at the end.

The first launch after updating spends a few seconds building the new conversation index before mail starts syncing. This happens once.

Requires an Apple silicon Mac running **macOS 13 or later**.
