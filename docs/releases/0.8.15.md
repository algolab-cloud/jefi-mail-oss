# Jefi Mail 0.8.15

A cleaner calendar.

- **Events sit on top.** Event cards are solid, so the grid's hour lines no longer show through them, and the line marking the current time sits cleanly above the day's edge.

Requires an Apple silicon Mac running **macOS 13 or later**.
